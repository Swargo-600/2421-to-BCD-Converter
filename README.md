# 2421 Code-to-BCD Converter

## Project Overview

This project focuses on the design and hardware implementation of a 2421 code-to-BCD converter as an individual project for the Digital Logic Design (DLD) course.

The converter translates valid 2421 code inputs into their corresponding Binary-Coded Decimal (BCD) outputs using combinational logic.

## Project Objectives

- Understand the 2421 code and Binary-Coded Decimal (BCD) representation.
- Develop a truth table for the code conversion process.
- Design the logic circuit for converting 2421 code into BCD.
- Implement the designed circuit in hardware.
- Understand the practical application of digital logic concepts.
